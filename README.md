# RHINO ESSENCE API Resources
This repository contains resources for using NSSP and WA ESSENCE APIs for Washington healthcare encounter (syndromic surveillance) data. 

- Credentials management instructions and scripts
  - See the [ESSENCE Credentials Management Wiki](https://github.com/WA-RHINO/rhino-essence-api-resources/wiki/ESSENCE-Credentials-Management) for instructions on setting up and using your ESSENCE credentials.
- Helper functions for using both instances of ESSENCE
- Tutorials and templates to help your workflow
